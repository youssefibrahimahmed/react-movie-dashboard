# React Movie Dashboard

A responsive movie and TV show dashboard built with **React**. Users can browse titles, explore trending shows, search for content, and view detailed information through a dashboard interface.

## Live Demo

[Open the live application](https://react-movie-dashboard-4dbc.vercel.app/)

## Features

- User login and protected routes.
- Dashboard with movie-related statistics.
- Browse and search movies and shows.
- Explore trending titles.
- View title details in a modal.
- Global state management with Redux Toolkit.
- API data fetching with TanStack Query and Axios.
- Client-side navigation with React Router.
- Loading and error states.
- Form validation and reusable components.
- Responsive interface.

## Built With

- React
- Redux Toolkit
- TanStack Query
- React Router DOM
- Axios
- Tailwind CSS
- TVMaze API

## Getting Started

```bash
git clone https://github.com/youssefibrahimahmed/react-movie-dashboard.git
cd react-movie-dashboard
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## API

The application uses the public [TVMaze API](https://www.tvmaze.com/api).
